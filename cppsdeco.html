Unlike combinational circuits, flip-flops store state $Q$. Experiment with clock edge triggers and memory transitions.

SR (Set-Reset) Flip-Flop

Basic bi-stable memory cell. $S=1, R=0$ sets $Q=1$; $S=0, R=1$ resets $Q=0$. Simultaneous $S=R=1$ is invalid.

05 / Reference Guide

📚 Formula Sheet & Academic Links

🔹 Boolean Theorems

• De Morgan: (A·B)̅ = A̅ + B̅
• Inversion: (A̅)̅ = A
• Absorption: A + AB = A
• Distributive: A + BC = (A+B)(A+C)

🔹 Flip-Flop Equations

• SR FF: Q(n+1) = S + R̅Q
• JK FF: Q(n+1) = JQ̅ + K̅Q
• D FF: Q(n+1) = D
• T FF: Q(n+1) = T ⊕ Q

🔹 Standard TTL ICs

• 7400: Quad 2-In NAND
• 7408: Quad 2-In AND
• 7432: Quad 2-In OR
• 7486: Quad 2-In XOR
